# Finance Pro

## تطبيق مالي عربي لإدارة المصروفات والحسابات

**Finance Pro** تطبيق Android عربي يساعدك على تنظيم مصروفاتك اليومية، ومتابعة الحسابات، وإدارة الديون والسلف، والتخطيط المالي، وتصدير بياناتك بتنسيقات متعددة.

**تصميم وتطوير: حضروم**

> **هذه صفحة توزيع وتجربة فقط.** لا يحتوي هذا المستودع على كود التطبيق أو ملفات البناء؛ بل يحتوي على معلومات الإصدار وملف APK الجاهز للتجربة.

## أبرز الميزات

### إدارة المصروفات

- تسجيل المصروفات مع المبلغ والتصنيف والوصف.
- تعديل العملية بعد حفظها.
- حذف العمليات مع إمكانية استعادتها من سلة المحذوفات.
- البحث والتصفية حسب التاريخ والفئة والمبلغ.
- دعم إدخال الأرقام العربية وفواصل الآلاف.
- إظهار أو إخفاء وقت تسجيل العملية.

### الحسابات والمعاملات

- قسم **مدين - عليّ** لمتابعة المبالغ المستحقة لك أو عليك.
- قسم **دائن - ليّ** لمتابعة السلف والمبالغ المقدمة.
- إنشاء حساب جديد مع حفظ العملية داخله مباشرة.
- تسجيل عملية مستقلة دون الحاجة إلى فتح حساب رئيسي.
- إضافة الملاحظات وتعديل المبلغ والتاريخ والوقت.
- عرض الرصيد وسجل العمليات والتسديدات والاستلامات.

### الأموال القادمة والتوزيعات

- تسجيل الأموال المتوقعة ومواعيدها.
- إضافة توزيعات متعددة للمبلغ.
- حفظ الملاحظات وإظهارها في سجل العمليات.
- تعديل البيانات بعد الحفظ.

### الأهداف والميزانيات

- إنشاء أهداف مالية ومتابعة المساهمات.
- عرض نسبة الإنجاز الفعلية حتى عند تجاوز الهدف 100%.
- إنشاء ميزانية عامة أو ميزانية لفئة محددة.
- عرض العمليات المحتسبة ضمن الميزانية.
- إظهار نسبة الاستخدام والتجاوز دون منع تسجيل عمليات إضافية.

### التقارير والتصدير

- تقارير يومية وأسبوعية وشهرية وسنوية.
- اختيار فترة مخصصة بحرية.
- تصدير PDF وExcel وCSV وMarkdown.
- مشاركة وطباعة الحسابات والتقارير والإيصالات.
- تصدير صورة عادية أو صورة طويلة تشمل العمليات.
- إيصال عملية بتصميم منظم مع رقم مرجعي قابل للنسخ.

### النسخ الاحتياطي

- إنشاء نسخة احتياطية كاملة أو انتقائية.
- اختيار الإعدادات والحسابات والعمليات والأقسام المطلوبة فقط.
- تحديد الكل أو إلغاء التحديد.
- استعادة الأقسام المحددة دون استبدال بقية البيانات.

### المصارفة والعملات

- حاسبة مصارفة بالاتجاهين.
- أسعار افتراضية بالريال اليمني القديم للعملات الرئيسية.
- إمكانية تعديل سعر الصرف يدوياً.
- عرض السعر بصيغة واضحة: `1 عملة = ؟ ريال يمني`.

### المظهر والتجربة

- الوضع الفاتح والداكن والتلقائي حسب إعدادات الجهاز.
- ست باليتات لونية.
- تطبيق تغيير المظهر فوراً.
- دعم أحجام النص من 80% إلى 150%.
- دعم خط IBM Plex Sans Arabic.
- تحية صباحية أو مسائية باستخدام اسم المستخدم.
- دعم اتجاه RTL للواجهة العربية.
